# Intelligent Orchard Citrus Fruit Maturity Detection Dataset VOC+YOLO format with 1566 images in 2 categories

Dataset format: Pascal VOC format + YOLO format (txt file without split path, only containing jpg images and corresponding VOC format xml files and yolo format txt files)

Number of images (number of jpg files): 1566

Number of annotations (number of xml files): 1566

Number of annotations (number of txt files): 1566

Labeling category count: 2

Label category names (Note that the order of labels in the YOLO format does not correspond to this, but is based on the classes.txt file in the labels folder): ["ripe", "unripe"]

Number of boxes labeled in each category:

ripe frame count = 16806

Unripe frame count = 5465

Total frame count: 22271

Number of images per category:

Ripe occupies the number of images = 790

Unripe occupies the number of images = 780

Image resolution: 640x640

Using labelImg:

Annotation rules: Draw a rectangle around the category.

Important Notice: The dataset does not have separate training, validation, and test sets; you need to partition them yourself.

Special : This dataset does not guarantee the accuracy of the trained models or weight files.
